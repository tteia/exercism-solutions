# Bob

Exercism의 Java 트랙에 있는 Bob에 오신 것을 환영해요.
테스트를 실행하거나 코드를 제출하는 데 도움이 필요하면 `HELP.md`를 확인해 봐요.

## Introduction

Bob은 [나태한][lackadaisical] 십 대예요.
자기가 아주 쿨하다고 생각하길 좋아하죠.
그리고 어떤 일에도 절대 신나 하지 않아요.
그럼 쿨하지 않으니까요.

사람들이 말을 걸어도 돌아오는 대답은 몇 가지뿐이에요.

[lackadaisical]: https://www.collinsdictionary.com/dictionary/english/lackadaisical

## Instructions

이번 과제는 누군가 Bob에게 말을 걸거나 질문을 했을 때 Bob이 무엇이라고 답할지 판단하는 거예요.

Bob은 언제나 다섯 가지 중 하나로만 답해요.

- **"Sure."**
  질문을 하면 이렇게 답해요. 예를 들어 "How are you?" 같은 질문이죠.
  질문의 규칙은 물음표로 끝난다는 거예요.
- **"Whoa, chill out!"**
  소리를 지르면 이렇게 답해요.
  소리치는 규칙은 모든 글자를 대문자로 쓰는 거예요.
- **"Calm down, I know what I'm doing!"**
  소리치면서 질문을 하면 이렇게 말해요.
- **"Fine. Be that way!"**
  침묵에는 이렇게 답해요.
  침묵의 규칙은 아무 말도 하지 않거나, 여러 가지 공백 문자를 조합하는 거예요.
- **"Whatever."**
  그 밖의 다른 모든 것에는 이렇게 답해요.
